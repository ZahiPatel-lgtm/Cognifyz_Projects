# Cognifyz C/C++ Internship Projects 

This repository contains all the projects completed during my C/C++ Internship at Cognifyz Technologies.  
---

## Projects Included

### 1. String Reversal
A program that takes a string as input and displays the reversed string using loops and string manipulation techniques.

### 2. Calculator Program
A basic calculator that performs arithmetic operations such as addition, subtraction, multiplication, division and modulus using conditional statements.

### 3. Fibonacci Series Generator
A program that generates the Fibonacci sequence up to a user-defined number of terms using loops and arithmetic operations.

### 4. Guessing Game
An interactive number guessing game where the user tries to guess a randomly generated number with hints like “higher” or “lower”.

### 5. File Copy Program
A file handling project that copies the contents of one file into another using input/output stream operations.

### 6. Palindrome Checker
A program that checks whether a given word or phrase is a palindrome by comparing characters from both ends.

### 7. Student Grade Calculator
A project that calculates the average marks/grade of a student based on multiple subject inputs.

### 8. Array Sorting Program
A sorting application that arranges array elements in ascending or descending order using sorting algorithms.

### 9. Rock-Paper-Scissors Game
A simple console-based game where the user plays Rock-Paper-Scissors against the computer.

### 10. Inventory Management System
A mini inventory management system that allows users to add, search, and display items using arrays, structures, or classes.
